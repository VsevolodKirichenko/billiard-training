# Модель упражнений

Модель находится в `src/BilliardTraining.Api/Domain/Exercises`.
Она описывает упражнение; выполнение тренировки и сохранение в БД ещё не реализованы.
Примеры ниже показывают создание объектов C#, но пока не вызываются из API.

## Ответственность классов

| Тип | Ответственность |
| --- | --- |
| `Exercise` | Название, описание, исходная расстановка и упорядоченные шаги |
| `ExerciseStep` | Инструкция и необязательная расстановка для установки перед шагом |
| `BallLayout` | Состав расстановки |
| `BallPlacement` | Роль и положение размещённого шара |
| `BallRole` | `Cue` — биток, `Object` — прицельный шар |
| `TablePosition` | Координаты центра шара на схеме |

Координаты относительные: `(0, 0)` — верхний левый угол игровой области,
`(1, 1)` — нижний правый, `(0.5, 0.5)` — центр. X растёт вправо, Y вниз.
Это соглашение приложения. Радиус шара и физическая геометрия стола пока не учитываются.

## Цепочка зависимых ударов

Координаты в примере условные: они демонстрируют модель, а не проверенную у стола расстановку.

```csharp
using BilliardTraining.Api.Domain.Exercises;

var initialLayout = new BallLayout(new[]
{
    new BallPlacement(BallRole.Cue, new TablePosition(0.25, 0.25)),
    new BallPlacement(BallRole.Object, new TablePosition(0.1, 0.1))
});

var steps = new[]
{
    new ExerciseStep("Забить чужой на клапсе."),
    new ExerciseStep("Новым битком с руки забить оставшийся шар с оттяжкой."),
    new ExerciseStep("Новым битком с руки забить оттянутый шар с накатом к лузе.")
};

var exercise = new Exercise(
    "Клапс → оттяжка → накат",
    initialLayout,
    steps,
    "Повторять цикл. После промаха восстановить исходную расстановку.");
```

В этих шагах `SetupLayout` не задана: отдельная установка по фиксированной схеме
не описана. Действия над оставшимся шаром заданы инструкциями.
Программа пока не вычисляет положения шаров, не переключает шаги и не обрабатывает промах.
Условия повторения и установки с руки остаются текстом для игрока.

## Смена фиксированной расстановки

Следующий пример независим от предыдущего; координаты также условные.

```csharp
using BilliardTraining.Api.Domain.Exercises;

var nearLayout = new BallLayout(new[]
{
    new BallPlacement(BallRole.Cue, new TablePosition(0.5, 0.4)),
    new BallPlacement(BallRole.Object, new TablePosition(0.5, 0.2))
});

var farLayout = new BallLayout(new[]
{
    new BallPlacement(BallRole.Cue, new TablePosition(0.5, 0.8)),
    new BallPlacement(BallRole.Object, new TablePosition(0.5, 0.2))
});

var exercise = new Exercise(
    "Удары с двух дистанций",
    nearLayout,
    new[]
    {
        new ExerciseStep("Выполнить удар из исходной расстановки."),
        new ExerciseStep("Установить вторую расстановку и выполнить удар.", farLayout)
    });
```

`InitialLayout` описывает исходную схему упражнения. `SetupLayout` второго шага
описывает отдельную установку перед этим шагом. Отсутствие `SetupLayout` не означает
автоматический возврат к исходной схеме.

## Правила и ограничения первой версии

- Название упражнения и инструкция шага не могут быть пустыми или пробельными.
- У упражнения должна быть исходная расстановка и хотя бы один шаг.
- Расстановка содержит хотя бы один шар и не более одного битка; элементы `null` запрещены.
- Фиксированный биток необязателен. Его отсутствие само по себе не задаёт правило установки с руки.
- Координаты — конечные числа от 0 до 1 включительно. Пересечения шаров и расстояния до бортов не проверяются.
- Коллекции шагов и шаров копируются при создании и предоставляются только для чтения.
- Нет редактора, целевых луз, формальных правил переходов, результатов, владельцев и доступа.
- Модель пока не подключена к HTTP-маршрутам; доступен только прежний `GET /` с названием API.

## Дальнейшее хранение

Принято разделение доменных моделей и моделей хранения: будущие `DbModel`
будут преобразовываться в доменные объекты и обратно отдельными ручными мапперами.
Домен не должен зависеть от моделей хранения или ORM.

Конкретная схема таблиц и ORM ещё не выбраны. При загрузке нужно будет восстанавливать
существующий идентификатор упражнения, порядок шагов и вложенные расстановки.
Текущий конструктор `Exercise` создаёт новый идентификатор; механизм восстановления ещё не добавлен.
